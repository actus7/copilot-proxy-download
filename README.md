# Copilot Proxy — Downloads

Download temporário do Copilot Proxy portátil.

**[Baixar a versão mais recente para Windows x64](https://github.com/actus7/copilot-proxy-download/releases/latest)**

1. Na página do release, baixe o arquivo **Windows-x64-Portable.zip**.
2. Extraia a pasta inteira para uma pasta gravável ou pendrive.
3. Se a versão anterior estiver aberta, escolha **Sair** no ícone da bandeja.
4. Execute **Iniciar-Copilot-Proxy.cmd** e siga o painel.

Requer Windows 10/11 x64. O pacote inclui o aplicativo, o iniciador, as instruções, a licença e as atribuições. A sessão Microsoft e a chave local ficam no perfil/cofre de cada usuário Windows.

O executável não possui assinatura Authenticode; o Windows pode mostrar um aviso de editor desconhecido. Os arquivos **SHA256SUMS.txt** permitem conferir a integridade do download e do conteúdo extraído.

As atualizações deste pacote são instaladas manualmente. Consulte as notas do release para conhecer as correções e a validação de cada compilação.
